Accessible Modal Dialog Component

A production-grade, zero-dependency interactive UI component built with semantic HTML5, modern responsive CSS, and resilient Vanilla JavaScript.

WAI-ARIA 1.2 Compliant WCAG 2.1 AA Focus Trap Zero Dependencies Light & Dark Mode Reduced Motion Support

1. Interactive Form Modal

Features automatic focus placement on the first input, full keyboard tab cycling, and backdrop dismissal.

2. Critical Confirmation (Alert)

Employs role="alertdialog" for urgent notifications, placing initial focus on the safe "Cancel" action.

3. Off-Canvas Drawer Variant

Slide-over panel layout ideal for mobile menus, filter drawers, or contextual settings panels.

4. Scrollable Long-Content Modal

Prevents page body scroll while preserving scrollbar width compensation to eliminate layout shift.

5. Stacked / Nested Modals

Handles multi-layer modal stacks with LIFO keyboard focus management and independent dismissal.

Run programmatic unit and accessibility verification tests for DOM manipulation and focus trapping.
